## Resumo do Sistema

## O Portal da Escola Técnica é um protótipo funcional de um site voltado para a comunicação interna de uma instituição de ensino técnico. Ele centraliza três funções principais que hoje costumam ficar espalhadas entre grupos de WhatsApp, e-mails e quadros de avisos físicos:

## Avisos institucionais — permite à escola publicar comunicados (ex: suspensão de aulas, eventos, mudanças de horário), definindo a prioridade (normal ou urgente) e para quem se destina (todos, professores, alunos ou responsáveis). Os avisos ficam listados em ordem cronológica, com os mais recentes no topo.
## Agendamento de reuniões — permite marcar reuniões (conselhos de classe, reuniões pedagógicas, etc.) informando assunto, data, horário, local e participantes. As reuniões ficam organizadas por ordem de data, facilitando visualizar a agenda da escola.
## Indicação para comissões — permite registrar quando um professor é indicado para participar de uma comissão (ex: comissão de formatura, de eventos, disciplinar), com espaço para uma observação sobre o motivo ou prazo.

## Na prática, o sistema funciona como um painel único onde a coordenação cadastra essas informações e qualquer pessoa com acesso ao site consegue visualizar. Os dados ficam salvos no navegador de quem usa, então nada se perde ao fechar ou recarregar a página.

## É um protótipo de demonstração: hoje roda localmente, sem login de usuários e sem compartilhar dados entre dispositivos diferentes. Para virar um sistema de uso real na escola, os próximos passos seriam adicionar autenticação (login de professor, coordenação e aluno) e um banco de dados compartilhado, para que todos vejam as mesmas informações ao mesmo tempo.
